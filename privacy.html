Privacy Policy

Effective date: 9 October 2026

OpenClaw Personal Assistant ("the application") is a private tool operated by Hunter House for personal use only. The only user of the application is its owner. This policy explains what Google user data the application accesses and how that data is handled.

Data accessed

With the owner's consent through Google sign-in, the application accesses:

  • Gmail: message content, headers, labels, and the ability to send messages from the owner's account.
  • Google Calendar: event details and the ability to create and modify events in the owner's calendars.

How data is used

Data is used solely to carry out tasks the owner asks the assistant to perform, such as summarizing email, drafting replies, and managing calendar events. It is not used for advertising, profiling, or any purpose unrelated to the owner's own requests.

Storage and retention

OAuth tokens and any cached data are stored on a server controlled by the owner. Data is retained only as long as needed to perform the requested task and can be deleted by the owner at any time. Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens.

Sharing

Google user data is never sold, rented, or shared with third parties. It is not transferred to anyone other than the owner, except as required by law.

Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Any change to this policy will be published on this page with an updated effective date.
